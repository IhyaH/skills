# TJC 系列差异

这份表只记录当前离线官方文档中能直接确认的差异，不补推测。

## 通用适用范围

- 官方首页说明本文档适用于淘晶驰所有串口屏系列，包括 `X5`、`X3`、`X2`、`K0`、`T1`、`T0`。

## 已确认差异

### 串口电平

- 文档明确提到：某些 `X3`、`X5` 系列串口屏的 TX 输出是 `5V` 电平。
- 官方建议：部分 `3.3V` 单片机若接收异常，可在“屏 TX -> MCU RX”之间串 `1K` 电阻。
- 当前 skill 不把这条推广到所有系列。

### 屏端串口缓冲区

- 官方 FAQ 及主动解析材料中提及的缓冲区参考值：
  - `X2/X3/X5` 系列约 `4KB`
  - `T0/T1/K0` 系列约 `1KB`
- 上述数值在官方文档中以 recmod / `com_stop` / `u[]` 数组等上下文出现，实际行为仍建议以目标型号规格书为准。

生成代码时：

- 面向 `T0/T1/K0` 发送长文本要更保守，必要时拆帧。
- 排查 `0x24` 溢出时，先核对目标型号的串口缓冲区能力。

### X 系列专属或明确偏向 X 系列的能力

官方控件页多次明确：

- `drag` 属性：仅 `X` 系列支持
- `aph` 属性：仅 `X` 系列支持
- `effect` 属性：仅 `X` 系列支持
- 部分透明/位置运行时修改能力：常见为 `X` 系列支持，其他系列不一定支持

因此：

- 生成运行时拖动、透明度、特效代码前先确认目标是 X 系列。
- 不要默认 `T0/T1/K0` 也支持这些属性。

### 系统变量/能力的文档明确限制

- `rtc0`：当前文档材料显示仅 `K0/X5` 相关场景中出现
- `volume`：文档材料显示仅部分带喇叭型号或相关系列支持
- 深度睡眠：历史说明中仅见 `T1` 支持深度睡眠，其他系列仅普通睡眠

这类能力在没有更明确页证实前，代码里必须带上“按当前文档仅确认某系列支持”的注释。

## 代码生成建议

### 未知系列时

默认采取最保守策略：

- 不生成 X 系列专属属性控制
- 长文本按小缓冲区思路处理
- 不使用未确认系列支持的系统变量或多媒体能力

### 用户指定系列时

先用下面顺序检查：

1. 是否涉及电平兼容
2. 是否涉及长文本/高频串口发送
3. 是否用了 X 系列专属属性
4. 是否用了特定系列的系统变量或多媒体能力
