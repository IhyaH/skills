# TJC 控件知识速查

这份参考专门服务于“MCU 代码与串口屏控件交互”场景。重点不是界面设计，而是：

- 这个控件主要通过 `txt` 还是 `val` 交互
- 哪些属性适合运行时通过串口修改
- MCU 常见控制方式
- 容易写错的点

## 通用规则

### 绿色属性和黑色属性

- 绿色属性：一般支持运行时通过指令修改。
- 黑色属性：一般只能在上位机里改，或仅可读不可改。

生成代码时遵守：

- 能用绿色属性就不要去改黑色属性。
- 遇到不确定属性，先保守处理为“设计时属性”，不要臆造运行时可改能力。

### 几乎所有控件都有的属性

| 属性 | 含义 | 运行时建议 |
| --- | --- | --- |
| `type` | 控件类型 ID | 只读 |
| `id` | 控件 ID / 图层顺序相关 | 不要运行时修改 |
| `objname` | 控件名 | 不要运行时修改 |
| `vscope` | 私有/全局作用域 | 设计时决定 |
| `drag` | 是否可拖动，常见于 X 系列 | 仅在确认机型支持时修改 |
| `aph` | 不透明度，常见于 X 系列 | 仅在确认机型支持时修改 |
| `effect` | 加载特效，常见于 X 系列 | 谨慎修改 |
| `x` | X 坐标 | 多数系列不建议运行时改 |
| `y` | Y 坐标 | 多数系列不建议运行时改 |
| `w` | 宽度 | 不可通过指令修改 |
| `h` | 高度 | 不可通过指令修改 |

### `txt` 和 `val`

| 属性 | 含义 | 赋值方式 | `get` 返回 |
| --- | --- | --- | --- |
| `txt` | 字符串内容 | `t0.txt="abc"` | `0x70` |
| `val` | 数值内容 | `n0.val=123` | `0x71` |

关键规则：

- `txt` 赋值要带双引号。
- `val` 赋值不要带双引号。
- 如果控件页没明确说明，就不要默认它同时支持 `txt` 和 `val`。

### 跨页面

- 若要跨页面访问控件或变量，先确认 `vscope` 是全局。
- 文档明确提到有些行为不能跨页面，例如某些控件事件、波形加点、定时器运行等。

## 常用控件

### Page 页面控件

- 主要用途：页面切换、页面背景、页面事件。
- 常见控制：
  - `page main`
  - `page 2`
  - `dp=2`
- 关键点：
  - `page` 后面的 HMI 语句不会继续执行。
  - 推荐优先用页面名跳转，不要过度依赖页面 ID。
  - 页面背景常通过 `pic` 或背景色类属性控制。

### Text 文本控件

- 主要交互属性：`txt`
- 常见可改属性：
  - `txt`
  - `pco`
  - `bco`
  - `font`
  - `xcen`
  - `ycen`
- 常见代码：

```text
t0.txt="hello"
t0.txt=""
t0.txt+=" world"
```

- 易错点：
  - `txt_maxl` 不够会截断文本。
  - 中文编码必须与工程一致。
  - MCU 拼接指令时很容易漏掉转义引号。

### Number 数字控件

- 主要交互属性：`val`
- 常见可改属性：
  - `val`
  - `pco`
  - `bco`
  - `font`
- 常见代码：

```text
n0.val=100
get n0.val
```

- 易错点：
  - `val` 不是字符串。
  - `0x71` 要按 4 字节小端解析。

### Button 按钮控件

- 常见交互属性：
  - `txt`
  - 按下/弹起事件
- 常见可改属性：
  - `txt`
  - `bco`
  - `pco`
  - `pic`
  - `font`
- 常见模式：
  - 改按钮文字
  - 在弹起事件里翻页
  - 配合 `tsw` 实现禁用
  - 配合定时器实现长按、双击

- 易错点：
  - 按下/弹起是触摸动作，不等同于“开关状态”。
  - 如果要做自锁，优先考虑双态按钮而不是普通按钮。

### Dual-state_button 双态按钮

- 主要交互属性：`val`
- 典型含义：
  - `0` 表示关闭/弹起
  - `1` 表示开启/按下
- 适合做：
  - 开关类 UI
  - 模式启停

- 易错点：
  - 不要把它和普通按钮的按下/弹起事件语义混淆。

### Progress_bar 进度条

- 主要交互属性：`val`
- 常见可改属性：
  - `val`
  - `bco`
  - `pco`
  - `bpic`
  - `ppic`
- 适合做：
  - 百分比显示
  - 过程进度
  - 与数值变量同步

- 易错点：
  - `val` 应按整数处理。
  - 不要直接拿它当文本控件。

### Slider 滑块

- 主要交互属性：`val`
- 常见可改属性：
  - `val`
  - `maxval`
  - `minval`
- 适合做：
  - 亮度
  - 音量
  - 阈值调节

- 易错点：
  - 某些系统变量如亮度保存相关，频繁写入可能带来卡顿或寿命问题。
  - `minval=0` 时某些亮度场景可能导致黑屏不好恢复。

### Variable 变量控件

- 主要交互属性：
  - 数值模式用 `val`
  - 字符串模式用 `txt`
- 适合做：
  - 中间变量
  - 页面间数据桥接
  - 标志位

- 易错点：
  - 先确认变量控件当前模式，再决定发 `txt` 还是 `val`。

### Timer 定时器控件

- 主要交互属性：
  - `en`
  - `tim`
- 适合做：
  - 延时跳转
  - 周期刷新
  - 长按/双击辅助

- 易错点：
  - 定时器通常只在当前页面运行。
  - 改 `en` 或 `tim` 时可能重新计时。
  - 不要把它当 MCU 硬件定时器那样精确看待。

### Waveform 波形控件

- 主要交互方式：不是改 `txt`/`val`，而是用加点指令，如 `add`、`addt`
- 适合做：
  - 采样曲线
  - 实时波形

- 易错点：
  - 只能对当前页面的波形控件加点。
  - 数据范围、通道号、页面切换约束要特别小心。

### Hotspot 触摸热区

- 主要作用：不可见触发器
- 适合做：
  - 隐藏入口
  - 复用一段事件逻辑
  - 用 `click` 间接触发 HMI 逻辑

- 易错点：
  - 不要在自身逻辑里递归 `click` 自己。

### TouchCap 触摸捕捉

- 主要交互属性：`val`
- 典型用途：
  - 获取被点中的控件 ID
  - 做统一触摸分发
  - 单选互斥
  - 全局按键音

- 易错点：
  - 它捕捉的是真实触摸，不一定会被 `click` 指令触发。
  - 页面里多个触摸捕捉控件时，要注意实际生效规则。

### Checkbox 复选框

- 主要交互属性：`val`
- 典型语义：
  - `0` 未选中
  - `1` 选中
- 适合做：
  - 多选状态
  - 若干独立开关

### Radio 单选框

- 主要交互属性：`val`
- 关键点：
  - 单选框组未必自动互斥。
  - 常常需要配合触摸捕捉或自定义逻辑实现互斥。

- 易错点：
  - 不要想当然地认为多个单选框天然构成标准单选组。

### Switch 状态开关

- 主要交互属性：`val`
- 适合做：
  - 开/关类设置
  - 模式切换

- 易错点：
  - 某些系列支持情况不同，生成代码时要注明机型前提。

### ComboBox 下拉框

- 主要交互属性：
  - `txt`
  - `path`
- 适合做：
  - 选项列表
  - 字符串配置项选择

- 常见模式：
  - 通过 `path` 准备候选项
  - 读取 `cb0.txt` 获得当前选中项

- 易错点：
  - 列表内容长度受内存和最大长度属性限制。
  - 多行分隔、回车拼接规则要按文档来，不要自造格式。

## 控件交互模式速记

### MCU 改显示内容

- 文本类：`t0.txt="..."`、`b0.txt="..."`、`cb0.txt="..."`
- 数值类：`n0.val=...`、`j0.val=...`、`h0.val=...`

### MCU 读回控件状态

- 读文本：`get t0.txt`，解析 `0x70`
- 读数值：`get n0.val`，解析 `0x71`
- 读页面：常见 `sendme` 或页面返回相关机制，解析 `0x66`

### MCU 触发 HMI 逻辑

- `click 控件,1/0`
- `page 页面名`
- `vis 控件,0/1`
- `tsw 控件,0/1`
- `ref 控件`

## 生成代码时最容易犯的错

1. 把文本控件当数值控件，用了 `val`。
2. 把数值控件当文本控件，用了 `txt`。
3. 给 `txt` 赋值时忘记双引号。
4. 给 `val` 赋值时错误加了双引号。
5. 不确认 `txt_maxl` 或相关长度限制，直接发送长文本。
6. 误以为所有属性都支持运行时修改。
7. 误以为所有控件都能跨页面访问和触发。
8. 用页面 ID 写死跳转，后期页面调整后逻辑失效。
9. 把波形、定时器这类特殊控件当普通 `txt/val` 控件处理。
10. 没确认控件所属系列支持，就直接使用 X 系列特性。
