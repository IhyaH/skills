# TJC 接线与硬件注意事项

## 基本接线

- `MCU_TX -> 屏_RX`
- `MCU_RX -> 屏_TX`
- `MCU_GND -> 屏_GND`
- 屏幕供电按型号要求接入，额外供电时也必须共地

## 独占串口

- 连接串口屏的 USART 上不要再挂别的外设。
- 尤其不要把“已经接了板载 USB 转串口芯片”的串口同时拿去接屏。
- 在 STM32 开发板上，常见的调试串口很可能已经连到 USB 芯片，选型前先看原理图。

## 常见误接

- 把开发板的 USB 口当成普通 UART 用。
- 让 USB 转 TTL、MCU、串口屏同时挂在一组 TX/RX 上。
- 忘记共地。
- TX/RX 同名直连，没有交叉。

## 电平兼容

- 文档提到某些 `X3/X5` 系列屏的 TX 侧可能输出 `5V TTL`。
- 若 MCU 是 `3.3V` 且 RX 不耐 `5V`，要先确认硬件是否有电平兼容。
- 官方示例里给出的保守方案是在“屏 TX -> MCU RX”之间串 `1KΩ` 电阻，帮助部分 3.3V 单片机正确识别信号。

## 面向代码生成的提醒

- 生成驱动代码时，可以在初始化注释里明确写出“该 UART 需独占、需共地、需确认电平”。
- 若用户没有说明硬件型号，不要默认所有淘晶驰屏都是 3.3V 逻辑输出。
